## 🚀 Featured Project

### 🔐 Secure Corporate Financial Portal (SCFP): Graduation Project

A cloud-native financial web portal built with security in mind from the start.

- **Stack:** Python, Flask, SQLAlchemy, HTML5, Bootstrap 5, Microsoft Azure
- **Auth & access:** Microsoft Entra ID, MFA, RBAC
- **Data protection:** Row-Level Security, Always Encrypted, Dynamic Data Masking
- **Infrastructure:** Azure SQL, Blob Storage and Key Vault behind Private Endpoints, VNet isolation, NSGs and WAF
- **Testing:** checked against SQL injection, XSS, CSRF and privilege escalation
